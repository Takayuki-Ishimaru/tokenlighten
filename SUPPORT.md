# Support

TokenLighten is maintained on a best-effort basis. No uptime, response-time, resolution-time, compatibility, or other service-level agreement is provided.

## Where to ask

- Use GitHub Issues for reproducible bugs and feature requests.
- Use GitHub Discussions for setup and usage questions when Discussions are enabled.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities; do not report them publicly.
- See [release-docs/licensing.md](release-docs/licensing.md) for organizational adoption and redistribution terms. Direct product-integration and licensing permission requests to Takayuki Ishimaru through [@Takayuki-Ishimaru](https://github.com/Takayuki-Ishimaru).

When reporting a problem, include the TokenLighten version, operating system, Node.js version, installation method, relevant command output, and minimal reproduction steps. Remove source code, workspace paths, credentials, personal information, and other confidential data before posting.

Support policy and available channels may change in future releases.
